# ADR-01 Frontend

Status: proposed on 2026-10-19. Owner and reviewers must record their decision.

Candidate: Vue 3 + TypeScript

Alternatives: React + TypeScript; Angular

Rationale: Proposed: Vue. Vue experience was reported by Beybit. Components, forms and a review workspace fit the scope [T01–T03].

Trade-off: Do not claim a performance advantage without measurement. Prototype is portable HTML/JS, not a completed Vue application.

Approval and review evidence: not recorded.
