# Existing system comparison

## Method and limits

Four relevant CRM conversation-analysis systems are compared against the same eight criteria. Findings describe official documentation as checked on 19 October 2026, not hands-on tests. A missing claim means not verified in the cited material, never proof that a feature is absent. Feature availability depends on edition, configuration, region and language. No current price comparison is asserted.

## Findings and need for the proposed prototype

Summaries, transcripts and topic or keyword insights already exist. A claim that commercial CRMs lack automated interaction analysis is contradicted by their documentation [S01–S06]. Our rationale is a bounded engineering and evaluation project: implement a transparent source-linked workflow and compare methods under controlled conditions. A real business case remains unvalidated.

## Differentiation to evaluate

Planned features are explicit source-turn references, raw versus reviewed versions, a reproducible evaluation harness and a small deployable scope. These are project design choices. We have not established their uniqueness or commercial advantage. An existing CRM configured for the same user task is a relevant workflow alternative.

## Follow-up before selection

Check actual tenant entitlements and languages with the prospective client. Trial-test one feasible commercial system only after access and data permissions are established. Use the same task and inputs if a fair comparison becomes possible.
