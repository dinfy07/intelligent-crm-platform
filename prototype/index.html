Method and limits

This prototype uses , a deterministic baseline. Fixed keyword rules identify topics. Up to three source turns form an extractive summary of at most 120 words. Source references point to the extracted turns.

It does not use a trained language model, understand every paraphrase or establish factual completeness. Referencing a source turn helps inspection but does not prove that an interpretation is correct.

All sample records are fictional. Data stay in this browser where local storage is available. No API calls or external inference run. The production API, authentication, object-level permissions, durable jobs and model comparison remain planned work.
