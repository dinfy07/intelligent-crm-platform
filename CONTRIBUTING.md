# Contribution workflow

1. Select the corresponding YouTrack issue and check its acceptance criteria.
2. Create a branch named `feature/CRM-<number>-description`.
3. Commit related code and documentation with the issue ID in the message.
4. Open a pull request against `main`, linking the issue.
5. Another team member reviews the change before merge.
6. Add the PR link to YouTrack and update the issue status when its criteria are met.
7. Tag the reviewed checkpoint commit `pre-defense-1`.

Review responsibilities: Danial — UI integration; Akhmediyar — backend acceptance; Beybit — analysis output usability.

Keep credentials and customer records outside Git. Interview records use participant codes and retain only information covered by consent.
